プライバシーポリシー

BuilderOS（以下「当事業者」）は、当事業者のウェブサイトおよびアプリケーション「BuilderOS Outreach」における情報の取り扱いについて、本ポリシーを定めます。個人情報の重要性を認識して法令を守り、取得する情報を必要最小限にとどめることを基本方針とします。

本ポリシーの要点

  • 「BuilderOS Outreach」が Google アカウントから取得する権限は、メール送信（gmail.send）のみです。受信箱の閲覧権限は取得しません。
  • 認証情報は GitHub Secrets に暗号化して保管し、第三者へ提供・販売しません。
  • 送信先のメールアドレスは営業連絡の目的でのみ使用し、配信停止のご連絡があった場合は以後送信しません。

第1条　適用範囲

本ポリシーは、次のものに適用されます。

  • BuilderOS のウェブサイト（当事業者が運営するウェブページ一式）
  • BuilderOS Outreach（運営者本人が業務連絡メールの送信に使用する、当事業者自身のアプリケーション）

BuilderOS Outreach は運営者本人が自らの業務のために使用するアプリケーションで、不特定多数の利用者に提供するサービスではありません。本ポリシーにおける Google アカウントに関する記述は、運営者本人のアカウントを対象とします。

第2条　取得する情報と利用目的

当事業者が取り扱う情報と、その利用目的は次のとおりです。

  • お問い合わせ内容（お名前、メールアドレス、店舗名、お送りいただいた内容）：お問い合わせへの回答、ご相談・お見積もり・制作に関するご連絡のため
  • 無料相談の予約情報（TimeRex を通じて受け取るお名前、メールアドレス、ご希望の日時）：オンライン相談の日程調整と実施のため
  • 送信先情報（氏名・名称、公開されているビジネス用メールアドレス、公開されている事業・活動内容）：営業連絡の宛先選定と文面作成のため
  • Google アカウントの認証情報（OAuth により発行されるリフレッシュトークン等）：BuilderOS Outreach から業務連絡メールを送信するため

上記の目的の範囲を超えて情報を利用することはありません。

[アクセス解析ツールや Cookie を使用する場合は、その名称と取得する情報をここに記載]

第3条　Google API の利用について

BuilderOS Outreach は、Google アカウントの認証（OAuth 2.0）を用い、Google の Gmail API を利用します。取得する権限は次の1つのみです。

  • メール送信：https://www.googleapis.com/auth/gmail.send

この権限でできるのは、当事業者のアカウントからメールを送信することのみです。受信箱や既存のメールを閲覧する権限（gmail.readonly 等）は取得しておらず、受信メール・下書き・連絡先など、送信以外のデータにアクセスすることはありません。

Google API から取得した情報の利用および他アプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含みます）を遵守します。Google Workspace API から取得したデータを、汎用的な AI・機械学習モデルの開発、改善または学習に使用することはありません。

第4条　情報の保管と管理

取り扱う情報は、次のとおり保管します。

  • OAuth の認証情報（クライアント情報およびリフレッシュトークン）は、GitHub Secrets（GitHub の暗号化されたシークレット管理機能）に保管し、アプリケーションの実行時にのみ参照します。ソースコード、公開リポジトリ、ウェブサイト等に掲載することはありません。
  • 送信したメールは、当事業者の Gmail アカウントに保存されます。
  • 認証情報と送信先情報へアクセスできるのは、運営者本人のみです。

GitHub（GitHub, Inc.）と Gmail（Google LLC）は、いずれも米国の事業者が提供するサービスです。これらのサービス上で情報を保管しています。

第5条　保存期間と削除

  • お問い合わせ内容・予約情報：対応を終えてから3年間保存し、その後削除します。
  • 送信先情報：最後に連絡してから1年間保存し、その後削除します。
  • 配信停止のお申し出があった宛先：再送を防ぐため、配信停止リストにメールアドレスのみを保存し続けます。
  • 認証情報：利用をやめた時点で、Google アカウント側でアクセス権を取り消し、保管先から削除します。

保存期間が過ぎた情報は、速やかに削除します。期間内でも、第9条の窓口から削除をお申し出いただけます。

第6条　第三者への提供

当事業者は、取得した情報を第三者へ提供・販売することはありません。ただし、次の場合を除きます。

  • ご本人の同意がある場合
  • 法令に基づき開示が求められる場合

第7条　送信先情報の取り扱いと配信停止

営業連絡のために取り扱う送信先情報は、ウェブサイト等で公開されているビジネス用メールアドレスその他の公開情報をもとに収集したものです。これらの情報は、営業連絡の目的でのみ使用します。

  • サイト等に送信拒否の表示がある宛先には、メールを送信しません。
  • 配信停止のご連絡があった場合は、以後その宛先へメールを送信しません。配信停止リストで管理し、再送を防ぎます。
  • 配信停止のお申し出は、第9条の連絡先までご連絡ください。速やかに対応します。

第8条　安全管理と本ポリシーの変更

当事業者は、情報の漏えい、滅失または毀損を防ぐため、アクセス権限の限定、認証情報の暗号化された保管、利用目的を終えた情報の削除など、必要かつ適切な措置を講じます。

法令の改正や取り扱いの変更に応じて本ポリシーを改定することがあります。改定した場合は本ページで公表し、改定日を明記します。重要な変更は、本ページ上で分かりやすくお知らせします。
